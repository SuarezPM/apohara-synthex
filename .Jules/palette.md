## 2026-05-29 - Robust Loading State Management in Vanilla JS Forms
**Learning:** In vanilla HTML/JS applications, long-running asynchronous processes (like file generation or data pipelines) must explicitly manage the disabled state of all form controls (not just the submit button). Additionally, CSS hover states on buttons often incorrectly override visual disabled states unless pseudo-classes are specifically scoped (e.g., `:hover:not(:disabled)`). Finally, when temporarily modifying the text/content of a button with an inline SVG to show a loading state, the original structure must be safely cached (e.g. `const origHtml = btn.innerHTML`) and restored within a `try...finally` block to prevent the button from being permanently stuck in a loading state if an error occurs.
**Action:** Always wrap async DOM manipulations in `try...finally` to guarantee state restoration, explicitly disable sibling form inputs during long operations, and update CSS hover rules to exclude `:disabled` elements.
